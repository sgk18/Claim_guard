ClaimGuard Architecture

Pre-payment expense verification: WhatsApp intake, multi-agent fraud screening, manager approval

Ingestion

  • • WhatsApp Business Cloud API, no new app
  • • API Gateway + Lambda scale to zero
  • • Raw receipts in S3 with Object Lock
  • • EventBridge decouples intake from processing

Agent pipeline

  • • Step Functions runs OCR, policy, risk, GST
  • • Textract extracts vendor, amount, date, GSTIN
  • • Duplicate, route and GSTIN/ITC checks
  • • Bedrock returns a risk score with reasons

Decision and audit

  • • AI assists, the manager decides
  • • Approve or reject from WhatsApp or dashboard
  • • DynamoDB holds claims, policy and audit trail
  • • Ledger export to Tally, Zoho Books, SAP
